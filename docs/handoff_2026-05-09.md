## 5. 当前代码状态

### Op schema（`src/graphmemory/graph_construction.py`）

只剩 6 类 op：

```
EnsureEntity / EnsureEvent / Relate / AttachAttr / MergeNode / Skip
```

`AddEdge / ReviseAttr / DeleteEdge / PruneNode / KeepSeparate` 在 `_dispatch` 里 deprecated 跳过。

### 执行层 guard

| Guard | 位置 | 拒绝什么 |
|-------|------|---------|
| `_is_allowed_predicate` | 第 707 行 | 非白名单 predicate / 空 / `related` |
| `_invalid_entity_event_edge` | 第 536 行 | Entity 名不在 Event text 的 entity-event 边 |
| `_is_session_container_event` | 第 650 行 | "X chat with Y" 之类 container event |
| `_is_low_value_abstract_event` | 第 662 行 | "kindness matters" 之类抽象 event |

### Predicate 白名单

```
entity-event:  participant / experienced / owns / attended / visited / decided
              / started / planned / achieved / object_of
event-event:   before / after / updates / inspired
entity-entity: same_as / family_of / friend_of / colleague_of / owns
```

### LLM call 日志

015 起 `build/llm_calls.jsonl` 记录每次 LLM 调用：messages / response / metadata（sample_id / batch_id / session_id / phase）。这是 **RL/SFT 数据的现成来源**。
